# LM Studio 划词翻译

用本机 LM Studio 翻译网页里选中的文字。给自己读日文轻小说用：划词、右键或快捷键出浮层，不改页面原文。

文本只发到你填写的本机地址。插件没有远程服务器，也不做统计。

## 安装

从 GitHub 克隆：

```
git clone https://github.com/creeper090729-kaze/lm-studio-translator.git
```

或下载仓库的 ZIP，解压后得到 `lm-studio-translator-main` 文件夹。不要用缺了 `icons` 的旧压缩包。

1. 打开 Chrome，地址栏输入 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选中含有 `manifest.json` 的那个文件夹。文件夹里面还套着一层同名目录时，选里面那层。
4. 刷新要看的网页。已经打开的页面要刷新一次，脚本才会挂上。

更新插件文件后，在扩展页点刷新，再刷新网页。工具栏图标出现「新」时，表示 GitHub 的 main 分支比本机版本高。打开插件弹窗可以进仓库下载。检查时只读取公开的 manifest.json，不上传翻译内容。

## LM Studio

1. 加载模型。阅读日文轻小说，8B 的 PLaMo Translate 可以。模型名里要能看到 plamo 和 translate。
2. Developer 里启动本地服务器，默认是 `http://127.0.0.1:1234`。
3. 不用开 CORS，也不用改 PLaMo 的提示词模板。插件认出翻译模型后，会按官方格式指定输出语言（简体中文是 `zh-hans`），不再走普通聊天提示。普通聊天提示会让它把日文原样吐回来。
4. 如果模型会先思考，关掉 Thinking / 推理。否则又慢，还可能只有思考、没有译文。
5. 没开 Require authentication 就不要填 Token。

## 用法

- 默认先选中文字，再右键点「用 LM Studio 翻译」。只框选不会翻译。
- 设置或工具栏弹窗里可以把触发方式改成「松开鼠标就翻译」。
- 快捷键默认 `Alt+Shift+T`。如果被占用，到 `chrome://extensions/shortcuts` 改。
- 浮层可以复制、重试、关闭。按 Esc 会关掉并取消这一次请求。
- 设置里可以把「结果显示」改成浏览器边栏。译文出现在窗口右侧，不盖住正文。右键和快捷键会尝试打开边栏；如果没看见，到工具栏弹窗点一次「打开边栏」，之后保持开着即可。
- 工具栏弹窗的「整页翻译」，或在网页上右键「整页翻译（按段落）」，会按段落逐段翻译当前页。一段一次请求；超过选区上限的段落再按句子切开，不会把全文一次交给模型。译文插在各段下面，不替换原文。同一个区块里用换行隔开的几段，译文会按顺序排在这个区块下面。页面下方可以停止或清除。再点一次、或按 Esc，也会停。划词翻译会打断整页翻译。

术语表在设置页，一行一条：

```
# 注释
アリス=爱丽丝
ギルド=公会
```

也支持 `=>` 和 Tab。最多 80 条。设置页的「试译一句」会把「こんにちは」发给本机，用来确认模型和提示词，不必先打开小说页。

## 稳定性上故意没做的事

- 不整页替换原文，避免把网页脚本弄坏。
- 不用流式输出，一次拿完整 JSON，失败就给出明确原因。
- 同一时间只跑一条翻译。新的选区会取消上一条，避免本地模型堆请求。
- 只允许 `localhost`、`127.0.0.1`、`::1`。
- 默认选区上限 2000 字、超时 45 秒、输出最多约 2048 token。过长的章节请分段选。
- 相同文本、相同术语表和模型会走本机缓存。缓存失败不影响翻译。

正文如果画在内嵌框架里，顶层页面的划词和整页翻译都碰不到它。多数小说站的正文在主页面里。
